# 图像增强曲线实测（2026-11-03）

## 数据与方法

同一静态房间场景下，依次发送曲线 0–4，并在每次 ACK 后抓取一帧 OBS 输入和 FPGA 输出。每条曲线只有一对帧；两路抓帧相差约 0.74–0.83 秒。以 OpenCV 的 8 位灰度值统计整帧平均亮度及第 90 百分位（P90）。本批次抓图时设备索引配置写反：原文件名 `*_hdmi.png` 对应 **OBS 输入（索引 3）**，`*_obs.png` 对应 **FPGA 输出（索引 2）**；下表和图表已按实际信号方向修正，不改动原始文件。

## 平均亮度

| 曲线 | 用途 | OBS 输入均值 | FPGA 输出均值 | 输出相对曲线 0 |
|---:|---|---:|---:|---:|
| 0 | 关闭增强 | 156.535 | 175.881 | 0.000 |
| 1 | 夜间提亮 | 156.537 | 217.187 | +41.306 |
| 2 | 强夜间提亮 | 156.730 | 236.929 | +61.048 |
| 3 | 高光压缩 | 157.710 | 155.873 | −20.008 |
| 4 | 强高光压缩 | 157.408 | 126.382 | −49.499 |

OBS 输入均值在 156.535–157.710 之间，仅波动 1.175 灰度级；FPGA 输出随曲线编号有明显且符合功能方向的变化。曲线 1、2 比关闭增强更亮，曲线 3、4 更暗，且 2 比 1 更强、4 比 3 更强。曲线 0 的 FPGA 输出均值与 OBS 输入本身不同，可能包含几何取样、视频链路和两路采集差异，因此评价曲线变化主要看同一路 FPGA 输出相对曲线 0 的差值。该组单帧结果支持曲线切换产生画面响应，但不提供帧间稳定性或重复测量误差。

## 高亮区响应

| 曲线 | OBS 输入 P90 | FPGA 输出 P90 |
|---:|---:|---:|
| 0 | 208 | 229 |
| 1 | 208 | 252 |
| 2 | 209 | 255 |
| 3 | 209 | 206 |
| 4 | 210 | 172 |

曲线 1、2 将高亮区推近或推到 8 位上限；曲线 3、4 压低了输出 P90，曲线 4 更明显。曲线 2 的 P90 达到 255，表明此场景出现高亮饱和风险。统计是整帧分位数，不等于同一像素逐点的 LUT 传递测量；后者需要空间配准和受控曝光。
