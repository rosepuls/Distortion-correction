# 图像矫正实测（2026-11-03）

## 数据与方法

对 `host/verification/0.png` 至 `7.png` 逐张显示，并通过 FPGA HDMI 输出与 USB 采集卡保存一帧，输出分辨率均为 1280×720。以下数据来自每个编号最新一次 `measurements.jsonl` 记录；较早拍到房间场景的记录未使用。棋盘直线度使用各图的完整 9×6 内角点，对角点行和列拟合直线，再计算点到线距离的第 95 百分位（P95；越小越直）。原图和输出图分别检测并计算同一指标。黑边比例是边界连通近黑像素的估计，按原图扣除部分原有暗内容。SFR/MTF50 只对脚本接受的斜边区域计算，单位为 cycles/captured-pixel。

## 棋盘直线度

| 图号 | 原图 P95 (px) | FPGA 输出 P95 (px) | P95 降幅 |
|---:|---:|---:|---:|
| 0 | 3.993 | 0.395 | 90.10% |
| 1 | 1.801 | 0.308 | 82.87% |
| 2 | 3.365 | 0.344 | 89.78% |
| 3 | 3.433 | 0.344 | 89.98% |

四张棋盘图均识别出完整 9×6 内角点。输出 P95 范围为 0.308–0.395 px，四图算术平均约 0.348 px；对应原图 P95 范围为 1.801–3.993 px。该对比支持这四张静态测试图的棋盘直线度得到改善。两端经不同采集路径，测量受重采样和角点定位影响；这不是几何标定误差的独立真值。

图 4、6、7 的红框为算法选中的不同斜边。MTF50 是各自图像区域的工程估计；斜边材质、对比度、拍摄角度和纹理不同，不能把这三个数值直接当作同一测试卡的横向清晰度排名。图 5 仅保留截图和黑边估计，不报告直线度或 SFR。黑边值可能受原图暗区域与矫正后的几何位置差异影响，应视作估计面积。
