# 文档插图与结构图制作规范

## 适用范围

适用于本项目技术文档中的流程图、系统框图、RTL 结构图及其他矢量插图。

## SVG 交付

- 输出可编辑的 SVG 矢量图，须能在 Adobe Illustrator 与 Microsoft Word 中正常显示框体、连线、箭头、文字和颜色。
- 优先使用 SVG 1.1 基础元素及显式属性。箭头由线段和三角形构成；框体、边线、颜色和字号直接写在元素属性中。
- 为提高兼容性，避免依赖 marker、filter、渐变、CSS class、外部字体/图像、脚本和链接资源。提交前解析 XML，需要兼容Word 和Illustrator 2025。
- 图内只保留理解图表所必需的节点名称、信号/数据流标签及必要分支标识。不添加解释段落、制作说明、来源注释或装饰性文字。
- 图中文字采用简体中文；模块名、信号名和标准缩写可保留英文。避免将长段说明塞进框体。

## 预览与文件管理

- 用户指定的目录只存放最终交付物及用户原有文件。
- 渲染预览、PDF、PNG、调试文件和临时脚本必须放在明确的临时检查目录中；不得放入 SVG 成品目录或其他无关文件夹。
- 完成检查后删除本次产生的临时文件，只报告最终交付文件路径。

## Word 文档检查

- 技术文档的常规编辑与检查直接基于 DOCX / Microsoft Word 完成；用户未明确要求时，不导出或另存 PDF。
- 用户明确表示无需核对时，停止渲染、截图及版式/内容核验，直接完成指定编辑，不继续执行检查。
- 仅交付用户指定的文件格式。临时检查文件须放在专用临时目录，并在检查完成后清理。
- 没有用户明确指令，不要修改文档，只发在聊天界面或单纯生成图片。

## 技能使用

- 制图前使用与任务相符的设计/图表技能，读取相关技能规范并按其要求规划版面、层级和视觉编码。
- 兼容性问题按系统化调试流程核实根因后修正；不能只依据 SVG 源码有效就宣称目标应用兼容。

## 绘图

- 以实际 RTL 顶层和模块连接为依据，准确表示时钟/复位、输入输出、主要模块、ready/valid 握手、DDR/缓存接口和帧元数据传递。
- 区分控制路径、像素/坐标数据路径和 DDR 存储通路；只纳入图表目标所需的层级，避免把软件流程、测试夹具或未集成功能画成当前硬件主链。
- 模块边界与接口方向明确；跨时钟域连接须标注同步/FIFO边界；参数配置只在实际 RTL 存在时显示其帧边界提交路径。
- 图题由 Word 正文中的图注承担；SVG 画布内不重复放置图题或额外说明。
- 示意图是示意讲解用的，不要画成结构图

## 当前文档架构图基线

- 本项目当前系统架构图以 `fpga/project/stage13_720p60_motion_stabilization_test` 为主线，除非用户明确指定其他工程版本，不得误用 Stage8 作为整机架构基线。
- Stage13 主线包含 Brown-Conrady K3、单应校正、输出源坐标上的运动平移补偿、双线性采样与重建，以及重建后、DDR 写回前的 RGB LUT 增强；图中应按实际 RTL 顺序呈现。
- 平移量由上位机估计并经 UART 传入，FPGA 应用补偿；不得把主机估计器误画成 FPGA RTL，也不得遗漏 FPGA 内的平移坐标补偿与 LUT 处理级。

## 写作禁忌

- 不得在文中出现stage几，全部用本项目。
- 不要新建word，全部在原word操作。
