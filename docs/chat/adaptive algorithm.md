# Stage 10 自适应插值实施计划

> 日期：2026-10-28。唯一复制基准：`fpga/project/stage8_720p60hz_bilinear_uart_angle_correction_65byte_k3_test`。新工程：`fpga/project/stage10_adaptive_interpolation_720p60hz`。本文件是实施计划；初始 Stage 10 副本仍运行基准双线性算法并保留标定 K3 Brown 映射。

**目标：**在同一个 FPGA 视频处理模式中，按最终输出到源图映射的局部缩放，自动选择双线性、Catmull–Rom 双三次或有界 EWA 插值。先做出正确画面，再测实际帧率并优化；最终目标是 1280×720 下持续处理并显示约 60 张新帧/秒。

**架构：**沿用基准的 HDMI 输入 → DDR 输入帧池 → 单应变换 → Brown 映射 → 坐标 FIFO → Tile Cache/DDR 读取 → 插值 → DDR 输出帧池 → HDMI 显示。只增加映射导数估计、自适应决策、可变邻域采样和统一输出汇合。没有 UART、编译期或板端手工算法模式。

**环境：**SystemVerilog、PDS 2022.2-SP6.4、Vivado Simulator 2020.2、Python 定点参考；RGBX8888，源坐标有符号 Q16.16，主处理时钟 125 MHz。

## 必须保持的基准接口

1. **视频与板级：**保持 1280×720 HDMI 输入/输出、现有 DDR 帧池与所有权、PLL、引脚及约束。`stage5_identity_pipeline.sv` 对 `frame_identity_transform_engine.sv` 的端口不变；DDR 读请求仍为 `read_valid/read_addr[27:0]/read_len[3:0]/read_reserve`，读返回仍为 256 位。帧首启动、`reader_idle/fault` 和输出帧物理排空语义不变。
2. **流元数据：**每个被接受的输出坐标恰好产生一个 RGBX8888 结果；`pixel_id[19:0]`、`frame_id[31:0]`、`param_version[15:0]`、`sof/eol/eof`、`geometry_valid` 经所有 ready/valid 停顿后仍原序到达写入端。无效坐标也产生带正确元数据的黑色像素。
3. **角度参数：**保留基准的 3×3 单应矩阵活动/待更新参数组，只在被接受的输出帧起始处原子提交。导数、选择结果及缓存窗口均绑定对应帧号和参数版本；不得跨源帧复用旧像素。
4. **65 字节 UART：**保留 B24 RX、C24 TX、115200/8-N-1、版本 `02`、65 字节请求/响应、矩阵偏移 7–42、偏移 43–62 的全零扩展区、偏移 63–64 的 CRC-16/CCITT-FALSE、ACK/NACK 和现有上位机脚本。自适应选择只发生在 FPGA 内部，不修改协议字段。
5. **镜头模型：**从指定基准原样继承标定 Brown `k1/k2/k3/p1/p2` 参数、分级定点流水和负 Y 修复；不得退回无 K3 的 65 字节 Stage 8 工程，也不从其他 K3 副本拼接实现。软件参考和板上比较使用同一参数、像素格式与边界规则。

## 首版决策和边界规则

对最终 Brown 输出的源坐标 `s(u,v)=(sx,sy)` 估计局部雅可比矩阵 `J=∂(sx,sy)/∂(u,v)`。基准在实际单应 + Brown 路径把 `j00–j11` 全部置零、`j_valid` 置零，因此现有 `j` 端口不能直接用于 EWA。首版在坐标 FIFO 前放一行 Q16.16 源坐标缓冲，用同帧、同参数版本、映射有效的左邻和上邻做后向差分：

```text
j00 = sx(u,v) - sx(u-1,v)     j01 = sx(u,v) - sx(u,v-1)
j10 = sy(u,v) - sy(u-1,v)     j11 = sy(u,v) - sy(u,v-1)
```

仅 `u>0,v>0` 且三点均有效时 `j_valid=1`。首行、首列、投影异常、溢出和无效导数回退双线性。行缓冲只在 `valid && ready` 时推进，不能把停顿周期当作相邻像素。仿真须证明帧首失效和参数版本对齐。

软件参考用 `J` 的奇异值 `σmax/σmin` 作首版判决；RTL 可用平方范数和比较器实现等价边界，避免每像素开平方。以下阈值是首版固定常数，不进入 UART；用实际标定画面和角度数据检查模式覆盖率后可在 Stage 10 内调整。

| 条件，按优先级 | 插值 |
| --- | --- |
| `j_valid=0` 或最终源坐标无效 | 双线性；2×2 邻域也不完整则按基准输出黑色 |
| `σmax >= 1.25` | 有界 EWA，最多 5×5、25 个源像素 |
| `σmax <= 0.85` 且 `σmin>0` | Catmull–Rom 双三次，4×4 |
| 其余 | 双线性，2×2 |

EWA 的椭圆方向/大小由 `J Jᵀ` 决定，在 5×5 支持域内用非负 LUT 权重累加 RGB，再按权重和归一化、舍入并饱和到 8 位。设计实现前，软件黄金参考须固定椭圆正则化、半径截断、权重量化、累加位宽、零权重处理和舍入规则。`σmax>2.0` 时仍使用受 5×5 限制的 EWA 并记录半径裁剪次数；该范围不声称完全消除混叠。双三次采用 Keys `a=-0.5`，参考现有 Stage 9 数值实现，但按本基准接口重新接入。

**统一边界：**保留基准严格 2×2 黑边规则。若选中的 4×4 或 EWA 支持域跨出源图，而 2×2 仍完整，则回退双线性；若 2×2 也不完整，则黑色。先用软件参考检查模式边界是否产生可见接缝或动态闪烁，再决定是否需要过渡混合；首版不额外计算第二套插值结果。
