# 阶段 3：相机标定与软件参考图实施计划

1. 保持当前显示正常的 RGBX8888 位流不变。标定数据必须来自最终工业相机、镜头和 UVC 1280×720 模式；没有照片时不生成示例内参冒充真实结果。
2. 增加上位机依赖清单和棋盘格采集说明。脚本接收内角点列数、行数、格距、照片目录和相机元数据。
3. 实现标定工具：筛掉读取失败、分辨率不符及未检测到棋盘格的照片；用有效照片计算 OpenCV 相机矩阵和完整畸变系数，保存每张图的重投影误差、输入文件哈希及 JSON。
4. 实现参考图工具：从标定 JSON 对指定 720p 原始图执行逆映射和双线性重采样，另存有效四邻域掩码与输出相机矩阵。检查 `k3` 对映射的像素影响；不得静默丢弃它。
5. 在 `docs/results/` 记录工具接口、当前数据缺口及现场采集步骤。收到真实照片后才填写实测内参、误差和参考图。
