# Stage13 Motion Stabilization Host Prototype

The Stage13 project is an isolated full copy of `stage11_720p60hz_adaptive_image_enhancement_calibrated_baseline`, chosen for its stable 720p60 pipeline and measured throughput. Stage12's 1080p super-resolution path is deferred until its timing is improved. This first increment implements a Python-side translation estimator for OBS/UVC frames and a shake-only compensation signal. It uses sparse Lucas–Kanade optical flow with robust outlier rejection to estimate apparent global frame translation. A causal low-pass trajectory separates sustained camera movement from high-frequency jitter; only the high-frequency component contributes to the compensation command. The command is bounded in source-image pixels and can be logged or sent through the existing 65-byte UART request with a Stage13 extension carrying signed Q16.16 dx/dy. Existing homography and lighting profile values must be preserved when packets are sent. FPGA protocol reception and frame-boundary application are a follow-on integration step; Stage11 remains unchanged.

The estimator is heuristic: image-only translation cannot identify the operator's intent perfectly. It should preserve sustained pans after the low-pass trend catches up, suppress alternating/rapid displacement, reject low-confidence flow, and expose its raw motion, trend, and correction for review. Synthetic translated-frame sequences and deterministic motion-stream tests are the acceptance basis for this host prototype.
