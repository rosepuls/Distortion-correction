# RGBX8888 视频链路测试页设计

日期：2026-10-19

## 目的

制作一个无依赖的单文件 HTML 测试页，用于检查 RGBX8888 HDMI→DDR3→HDMI 链路的颜色通道、字节序、画面稳定性和运行记录。测试页只生成并显示测试图，不读取或分析 FPGA 状态；闪屏、丢帧和欠读由操作者观察设备状态后手动记入。

## 页面与测试图

- 主测试画布按 1280×720 逻辑像素绘制，并按浏览器可用区域等比例显示。
- 提供红、绿、蓝、白、黑纯色，以及 RGB 交替条纹和棋盘格图案。
- 提供运动帧计数图案，带持续变化的帧编号和运动标记，便于观察刷新和重复画面。
- 控制面板可切换图案、开始/暂停运行计时、显示运行状态；按 F 键切换全屏并隐藏/显示控制面板，避免覆盖测试画面。

## 运行记录

- 记录运行开始时间、累计时长和手动事件。
- 可分别添加闪屏、丢帧、欠读事件，并显示各类累计次数及事件时间。
- 可将本次运行记录导出为 CSV，供阶段验收记录归档。
- 页面刷新后不承诺恢复运行状态；操作者应在结束前导出 CSV。

## 实现边界与验收

- 使用单个 HTML 文件和内嵌 CSS/JavaScript，不依赖网络、框架或外部资源。
- 页面显示 1280×720 测试画布；图案切换立即生效，运动帧计数持续更新。
- 纯色、条纹及棋盘格能够覆盖颜色通道和像素排列的目视检查。
- 计时与事件计数可操作，CSV 能包含本次运行信息和所有记录事件。
- 浏览器生成的帧编号仅用于观察测试图是否持续变化，不作为 HDMI 或 FPGA 实际帧率的测量值。
