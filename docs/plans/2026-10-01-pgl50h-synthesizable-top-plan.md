# PGL50H 可综合算法系统顶层实施计划

1. 先建立 `tb_mes50hp_top_image.sv` 和优化核心黄金数据生成测试，使缺失顶层的验证按预期失败。
2. 为 `distortion_image_pipeline.sv` 增加基准/优化核心参数化选择，保持默认行为兼容。
3. 新建板级复位同步器和 `rtl/board/mes50hp/mes50hp_top.sv`，实现整帧扫描及完成控制。
4. 新建 Q18 图片级矢量生成脚本，生成 256×192 彩色畸变输入及位精确矫正黄金结果。
5. 新建 XSim 运行脚本，将所有临时文件限制在指定的 `xsim.dir` 子目录。
6. 运行 Python 单元测试、既有关键 RTL 回归和新的图片级 XSim；把 RTL 输出还原成 PNG 并核对逐像素结果。
7. 更新板级 README，记录 PDS 顶层、源文件清单、50 MHz 时钟约束及仍需接入的厂商 IP。
