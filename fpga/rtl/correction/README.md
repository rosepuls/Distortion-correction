# 畸变矫正 RTL 接口

第一版映射接口由 `identity_mapper.sv` 固定。它用于先验证坐标格式、反压和元数据传递，后续 `brown_mapper` 和鱼眼映射器应保持相同的基础端口语义。

当前模块：

- `identity_mapper.sv`：输出单位映射坐标和单位雅可比矩阵。
- `coordinate_fifo.sv`：深度可配置的宽坐标队列，保存坐标、四个雅可比元素、有效标志和帧元数据；支持非二次幂深度以及满队列时同周期出队/入队。
- `identity_coordinate_pipeline.sv`：连接单位映射器与坐标队列，作为后续采样规划器的板卡无关输入级。
- `bilinear_sample_planner.sv`：将有符号 Q16.16 源坐标拆成 2×2 邻域、16 位水平/垂直权重和逐邻点有效掩码。
- `bilinear_interpolator.sv`：对读取完成的四个 RGBX8888 邻点执行位精确双线性插值并输出 RGBX8888。
- `demo_radial_mapper.sv`：Stage 4 板测用固定径向映射器，中心不变、边缘向外取样；它用于验证公共坐标接口，不代表真实镜头标定。
- `procedural_pixel_reader.sv`：片上生成白色网格和彩色渐变的四邻点读取替代层，用于在接入 DDR Tile Cache 前闭环验证算法。
- `stage4_demo_pipeline.sv`：连接径向映射器、坐标 FIFO、双线性规划器、片上源图和插值核。
- `stage4_demo_frame_source.sv`：把 HDMI 有效区转换为完整帧扫描请求，并检查输入停顿和输出像素序号。
- `stage4_demo_fram_buf.v`：与厂商视频顶层同端口的 Stage 4 板测包装器，关闭 DDR 业务请求并直接输出算法图像。

## 坐标约定

- 输出像素坐标 `s_u/s_v` 从左上像素中心 `(0,0)` 开始。
- 源坐标 `m_sx/m_sy` 是 32 位有符号 `Q16.16` 像素坐标。
- 坐标整数部分按数学 `floor` 解释，低 16 位是非负小数部分。
- 单位映射输出 `m_sx = s_u << 16`、`m_sy = s_v << 16`，并令 `m_geometry_valid=1`。
- 雅可比接口的 `m_j00/m_j01/m_j10/m_j11` 均为有符号 32 位 `Q16.16`，单位为源像素/输出像素。
- 单位映射输出精确的 `[[1,0],[0,1]]` 并令 `m_j_valid=1`。后续映射器内部可以使用更宽位宽，只在公共接口处执行范围检查和格式转换。

## 握手与元数据

- 输入和输出均采用 `valid/ready`；握手发生前发送方必须保持全部载荷稳定。
- 模块内部使用一级弹性寄存器。输出被消费的同一周期可以接收下一个坐标，稳态吞吐为每周期一个坐标。
- 输出反压时保持坐标、`pixel_id`、`frame_id`、`param_version`、`sof/eol/eof` 和有效标志不变。
- `rstn=0` 时清除在途坐标并拉低 `s_ready`，避免上游误判复位期间发生握手。
- `coordinate_fifo.level` 暴露当前队列水位；队列已满但下游同周期取走队头时，仍允许接收一个新坐标。

解析导数溢出、不可表示或不可用时，映射器必须清除 `m_j_valid`，不能静默截断。真实标定仍用于检查导数分布、采样足迹及性能，不再作为接口定宽的前置条件。

## 双线性采样规划

- `x0/y0` 使用源坐标的数学 `floor`，所以 `-0.25` 拆成整数 `-1` 和小数 `0xC000`。
- `fx/fy` 直接保留 Q16.16 的低 16 位；四邻域顺序固定为 `P00(x0,y0)`、`P10(x1,y0)`、`P01(x0,y1)`、`P11(x1,y1)`。
- `m_neighbor_valid[3:0]` 的位序依次对应 `P11/P01/P10/P00`，即 bit 0 对应 P00，bit 3 对应 P11。
- 输出地址始终夹紧到图像范围内。常量黑色模式按每个邻点分别判断有效性，越界邻点由后级注入黑色；复制边缘模式将四位掩码全部置一。
- `s_geometry_valid=0` 时，无论边界模式为何，四个邻点都无效。该标志与普通图像边界越界保持独立。
- 规划器采用一级弹性寄存器，遵守与映射器相同的 `valid/ready`、反压、元数据和复位约定。

## 双线性像素重建

- 插值核输入四个 32 位像素，通道布局为 `{R,G,B,X}`；仅处理高 24 位，输出低 8 位固定为 `8'h00`。
- 无效邻点在运算前替换为黑色且不重新归一化，因而能正确实现图像边缘处有效像素与常量黑色的加权混合。
- 水平和垂直权重均为无符号 Q0.16。每个颜色通道用 42 位中间量完成二维 Q0.32 累加，只在末尾执行一次四舍五入，规则为半值向上。
- `m_valid` 表示输出像素事务有效；`m_geometry_valid` 独立传递几何状态。即使几何无效，流水线仍输出一个黑色像素事务供帧写入器维持完整扫描。
- 当前实现先固定功能和位精确语义。PG2L200H Stage 4 演示工程的后布局时序已覆盖 74.2501 MHz 像素域，建立时间裕量为 1.611 ns。

## Stage 4 演示边界

- 固定径向演示公式为 `source = output + (output-center) * r² / 2²³`，公共输出仍为有符号 Q16.16。
- 演示映射器未计算局部导数，因此四个 Jacobian 元素置零并令 `J_valid=0`。
- 片上源图按整数源坐标生成 RGBX8888 渐变，每隔 64 像素产生白色网格线；四角越界后按常量黑色逐邻点混合。
- 完整 1280×720 仿真验证了 921,600 个连续像素、首点/中心/末点颜色、帧完成及无停顿。
- 此演示用于确认阶段 4 映射、边界、插值和 HDMI 输出。真实相机画面仍需后续 Tile Cache/DDR 读取器替换 `procedural_pixel_reader`。
